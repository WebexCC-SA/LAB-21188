# Prerequisites & Dependencies (Pre-Installation)

## Salesforce Environment requirements and limitations
*	Salesforce Lightning Experience is mandatory
*	Supported Salesforce Editions: Enterprise, Unlimited, Developer (Includes 5 Partner Telephony licenses)
*	Service Cloud Voice for Partner Telephony license
*	Omni-Channel Requirements
    - Omni-Channel must be enabled
    - Enhanced Omni-Channel required (Standard Omni-Channel EOL Spring '26)
*	Navigation Requirements
    - Apps with Console navigation only

## Webex Contact Center Requirements
*	Idle Code IDs for mapping in Salesforce 
    - Webex Control Hub > GUIDs
*	Certificate with public and private key 
    - Self-Signed OR CA Signed Cert for Flow Connector (Connected App)
